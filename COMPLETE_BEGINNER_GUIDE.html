🤖 EduBot — Complete Beginner Setup

From "I have a zip file" to "My chatbot is running!" — every single click explained.

📋 Your Setup Checklist (8 Steps, ~30 minutes total)

1. Install Node.js 2. Extract Zip 3. Open in VS Code 4. Open Terminal 5. Setup pnpm 6. Configure Project 7. Get API Keys 8. Run It!
1
Install Node.js (~3 minutes)

Node.js is the engine that runs JavaScript outside a browser. Your EduBot needs it.

  1. Open this link in your browser:

    🌐 Go to nodejs.org/download
  2. On the page, click the big green button that says "LTS" (Long Term Support). It will download a file like node-v22.x.x-x64.msi
  3. Go to your Downloads folder and double-click the downloaded .msi file
  4. The installer will open. Click through these screens:
    Next → ✅ I accept → Next → Next → ✅ Automatically install tools (check this!) → Next → Install → Yes (Windows permission popup) → Finish
  5. IMPORTANT: After installation, close ALL open terminals, CMD, PowerShell, and VS Code windows. This is so they can detect the new Node.js installation.

✅ Verify it worked: Press Windows Key + R, type cmd, press Enter. Then type node -v — you should see something like v22.15.0. If you see that, Node.js is installed!

2
Extract the Zip File (~1 minute)

The zip file I gave you contains all the project code. You need to extract (unzip) it first.

  1. Find the file EduBot-Fixed-Clean.zip in your Downloads folder
  2. Right-click on EduBot-Fixed-Clean.zip
  3. Click "Extract All..."
  4. A window pops up. Leave the default path and click "Extract"
  5. A folder will open with all your project files
⚠️

Don't skip this step! You CANNOT open a zip file directly in VS Code and run it. You MUST extract it first. If you see files like pnpm-workspace.yaml and folders like artifacts and lib, you're looking at the extracted folder — that's correct.

A folder window showing files like: .env.example, docker-compose.yml, package.json, pnpm-workspace.yaml, pnpm-workspace.local.yaml, README.md, and folders: artifacts, lib, scripts
3
Open the Folder in VS Code (~30 seconds)
  1. Open VS Code
    (Press Windows Key, type "vscode" or "Visual Studio Code", click it)
  2. In VS Code, click the menu: File (top-left corner)
  3. Click "Open Folder..."
    (Or press Ctrl + K then Ctrl + O)
  4. Navigate to your extracted folder and select the main folder (the one containing package.json)
  5. Click "Select Folder"
  6. If VS Code asks "Do you trust the authors of the files in this folder?" → Click "Yes, I trust the authors"

✅ You should now see a file explorer on the LEFT side of VS Code showing all the project files and folders.

⚠️

Wrong folder? If you opened a subfolder like artifacts/api-server instead of the root, things won't work. Make sure you can see package.json, pnpm-workspace.yaml, and the artifacts folder in the left panel.

4
Open the Terminal Inside VS Code (~10 seconds)

The terminal is where you type commands. VS Code has a built-in terminal at the bottom.

  1. Press Ctrl + ` (the backtick key — it's above the Tab key, next to the 1 key)
  2. OR: Click menu → View → Terminal
A dark panel at the bottom of VS Code showing a terminal with a blinking cursor. It might say something like PS C:\Users\YourName\...\EduBot-Fixed-Clean>

💡 From now on, ALL commands below will be typed into THIS terminal. You don't need to open a separate CMD or PowerShell window.

🔧 Setting Up the Project

5
Install pnpm (the Package Manager) (~1 minute)

pnpm is a tool that downloads all the libraries your project needs. Think of it like an app store for code.

Type this command in the VS Code terminal and press Enter:

corepack enable
✅ Expected Output
Nothing visible, or a short message. No errors = success.

Then type this:

corepack prepare pnpm@latest --activate
✅ Expected Output
Preparing pnpm@latest... done
Activating pnpm@10.x.x... done

Verify it worked:

pnpm -v
✅ Expected Output
10.12.1 (or similar number — any version is fine!)
⚠️

If corepack enable gives an error saying "not recognized", try this instead: npm install -g pnpm

6
Switch to Windows-Friendly Config (~10 seconds)

The original project was built on Replit (Linux). Some settings block Windows. We need to swap the config file.

Type this in the terminal:

copy pnpm-workspace.local.yaml pnpm-workspace.yaml

If it asks "Overwrite?" → type Y and press Enter.

✅ Expected Output
1 file(s) copied.

💡 What this does: The original config removes Windows versions of tools like esbuild to save space on Replit. This local version keeps them so everything works on your Windows PC.

7
Create Your .env File (Settings) (~1 minute)

The .env file stores your project's secret settings (API keys, database URL, etc.)

Step A: Create the file by copying the template. Type this in terminal:

copy .env.example .env

Step B: Now open the .env file in VS Code:

Look at the left panel (Explorer) → Find .env → Click it to open

You'll see this content:

PORT=8080 NODE_ENV=development DATABASE_URL=postgresql://postgres:postgres@localhost:5432/edubot GEMINI_API_KEY=

Leave it as-is for now — we'll fill in the API key in the next step.

🔑 Getting Your Free API Keys

8
Get a Free Gemini API Key (~3 minutes)

Your chatbot uses Google's Gemini AI to generate responses. You need a free API key.

  1. Open this link in your browser:

    🔑 Go to Google AI Studio
  2. Sign in with your Google account (Gmail)
  3. Click "Create API Key"
  4. Choose "Create API key in new project" (or any existing project)
  5. Your key will appear — it starts with AIza...
  6. Click the copy button next to the key

Now paste it into your .env file:

Go back to VS Code → click the .env file → find the last line that says GEMINI_API_KEY= and paste your key after the = sign:

GEMINI_API_KEY=AIzaSyB...........................(your long key here)

Press Ctrl + S to save the file.

⚠️

NEVER share your API key with anyone! Don't post it online, don't send it in screenshots. It's like a password.

9
Get a Free Database (Neon) (~5 minutes)

Your chatbot saves conversations in a database. Since you don't have Docker, we'll use Neon — a free cloud database (just like what Replit uses).

  1. Open this link:

    🌐 Go to neon.tech
  2. Click "Sign Up" (top right) → Sign up with your Google/GitHub account
  3. After signing in, click "Create Project"
  4. Fill in:
    • Project name: edubot
    • Region: Choose the one closest to you (e.g., Asia Southeast for India)
    • Leave everything else as default
  5. Click "Create Project"
  6. On the next screen, you'll see a connection string. It looks like:
    postgresql://neondb_owner:xxxxx@ep-xyz.ap-southeast-1.aws.neon.tech/neondb?sslmode=require
  7. Click the copy button next to it

Now paste it into your .env file:

Go back to VS Code → open .env → find the line DATABASE_URL= → replace everything after = with your Neon connection string:

DATABASE_URL=postgresql://neondb_owner:xxxxx@ep-xyz.ap-southeast-1.aws.neon.tech/neondb?sslmode=require

Press Ctrl + S to save.

✅ That's it! Neon is free forever for personal projects. No credit card needed. You now have a cloud database just like Replit had.

📦 Installing & Building

10
Install All Dependencies (~3-5 minutes)

This downloads all the code libraries your project needs. Type this in the terminal:

pnpm install
You'll see a LOT of text scrolling by — package names downloading. This is normal. Wait for it to finish. It might take 3-5 minutes on first run.
✅ Expected Output (at the end)
Done in 2m 34s
Packages: +847
...
⚠️

If you see errors:

• "Use pnpm instead" → You accidentally typed npm install. Use pnpm install instead.

• "esbuild binary not found" → You forgot Step 6 (copy pnpm-workspace.local.yaml). Go back and do it.

• "'pnpm' is not recognized" → Go back to Step 5 and install pnpm.

11
Generate API Types (~30 seconds)

This creates TypeScript type definitions for the API. Copy-paste each command one by one:

pnpm --filter @workspace/api-spec run codegen
✅ Expected Output
Done in 5s (or similar)
12
Set Up the Database (~30 seconds)

This creates the tables (conversations, messages) in your Neon database:

pnpm --filter @workspace/db run push
✅ Expected Output
✓ Your database is now in sync with your schema
[✓] Done in 3s
⚠️

If you see ECONNREFUSED or connection errors → Your DATABASE_URL in the .env file is wrong. Go back to Step 9 and re-copy the Neon connection string.

13
Build the Project (~1 minute)

This compiles all the TypeScript code into JavaScript that Node.js can run:

pnpm run build
Lots of text. It might show some warnings (yellow text) — that's OK. As long as it doesn't show red errors, you're fine.
✅ Expected Output
Done in 45s (or similar — it compiles all packages)

🚀 Running Your EduBot!

14
Start the Backend Server (~10 seconds)

The backend handles all the AI and database logic. Type this in the terminal:

pnpm --filter @workspace/api-server run dev
✅ Expected Output
[INFO] Server listening { port: 8080 }

✅ Backend is running! Don't close this terminal — leave it running.

💡 If you see Server listening { port: 8080 }, the backend is alive! You can test it by opening http://localhost:8080/api/healthz in your browser — you should see {"status":"ok"}

15
Open a Second Terminal & Start Frontend (~10 seconds)

You need a SECOND terminal for the frontend (the backend is still running in the first one).

To create a second terminal:

Look at the terminal panel at the bottom → Find the + icon (top-right of terminal panel) → Click the + to create a new terminal
You'll see two terminal tabs at the bottom — "bash" and "bash (2)" or similar. Click on the new one (the second tab).

In this new terminal, type:

pnpm --filter @workspace/student-chatbot run dev
✅ Expected Output
VITE v7.x.x ready in 2000 ms

➜ Local: http://localhost:5173/
➜ Network: http://0.0.0.0:5173/

🎉 YOUR EDUBOT IS RUNNING!

16
Open EduBot in Your Browser! 🎉

Hold Ctrl and click this link in the terminal output:

http://localhost:5173/

OR manually open your browser and type http://localhost:5173 in the address bar.

🎉🎉🎉 CONGRATULATIONS! Your EduBot chatbot should now be visible in your browser! 🎉🎉🎉

Try typing a message like "Tell me about college admissions in India" and watch your AI chatbot respond!

🔧 Something Went Wrong?

?
Troubleshooting — Common Problems
❌

Problem: "'pnpm' is not recognized as an internal or external command"
Fix: Go back to Step 5. Run npm install -g pnpm instead.

❌

Problem: "Use pnpm instead" when running install
Fix: You typed npm install. Use pnpm install instead.

❌

Problem: "esbuild: Failed to find package @esbuild/win32-x64"
Fix: Go back to Step 6. Run copy pnpm-workspace.local.yaml pnpm-workspace.yaml then pnpm install again.

❌

Problem: "DATABASE_URL must be set" or ECONNREFUSED
Fix: Check your .env file. The DATABASE_URL line should have your Neon connection string (Step 9). Make sure it starts with postgresql://.

❌

Problem: "'export' is not recognized"
Fix: You're using old code. Make sure you downloaded the fixed zip I gave you.

❌

Problem: Frontend shows blank white page
Fix: Open browser DevTools (F12) → Console tab → check for red errors. Most likely the backend isn't running or the API URL is wrong.

❌

Problem: Chatbot doesn't respond / shows error when sending messages
Fix: Check your GEMINI_API_KEY in .env. Make sure it starts with AIza and has no extra spaces.

💡 Still stuck? Copy the EXACT error message from your terminal and send it to me — I'll tell you exactly what to fix!
